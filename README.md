# Ten Sittings content

Signed book catalog for the Ten Sittings iOS app.

- `catalog.json` lists downloadable guided editions; `catalog.json.sig` is its detached Ed25519 signature, verified by the app.
- Book files are attached to GitHub Releases and verified by SHA-256.

Texts are from [Standard Ebooks](https://standardebooks.org) and are in the public domain (CC0).
